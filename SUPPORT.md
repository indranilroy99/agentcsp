# Support

AgentCSP is an open-source project and does not currently provide a commercial support SLA.

Use the appropriate channel:

- **Bug or regression:** open a GitHub issue with a minimal sanitized reproduction.
- **Detection quality:** include the rule ID, redacted normalized fields, expected result, and AgentCSP version.
- **Feature proposal:** describe the security-team workflow, trust boundary, and evidence required.
- **Usage question:** open a GitHub discussion or issue after checking `README.md` and `docs/usage.md`.
- **Vulnerability:** use the private process in [`SECURITY.md`](SECURITY.md).

Never attach real secrets, private prompts, customer data, internal URLs, raw memory, or production transcripts. Replace sensitive values with clearly labeled synthetic placeholders.
