# Code of Conduct

AgentCSP is committed to a professional, respectful, and technically rigorous community.

Contributors and maintainers are expected to:

- discuss ideas and code without personal attacks
- welcome questions and differing levels of experience
- give specific, actionable review feedback
- respect privacy and avoid posting sensitive security material publicly
- disclose conflicts of interest that affect security or governance decisions
- accept evidence-based correction when a claim or detection is too broad

Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate disruption are not accepted in project spaces.

Maintainers may edit or remove content, close discussions, or restrict participation when needed to protect the community or the project's security process. Serious or sensitive concerns should be raised privately through the repository owner's GitHub contact channel. Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).
